# 媒体笔记索引

主产物笔记按**分类**存放在 `media-note/` 子目录中；笔记引用的静态资源统一放在 `assets/`（子目录笔记内以 `../assets/` 引用）。新增一篇就往对应分类的表里加一行，日期用笔记生成或合并当天。

## 分类

| 分类 | 说明 | 笔记数 |
| --- | --- | --- |
| `AI 工具指南` | AI skills、插件等工具的使用与实战 | 2 |
| `软件使用说明` | 具体软件 / Agent 产品的使用说明 | 2 |
| `开发教程` | RAG、Agent、源码工程等开发向教程 | 13 |
| `学习路线` | 阶段式学习路线 | 1 |
| `编程基础` | 通用编程基础概念 | 1 |

**系列规则**：同一视频合集（同一 UP 主的系列、不同分 P）的笔记必须放在同一系列子文件夹中，如 `开发教程/Agent方法论/`、`开发教程/Playwright 系列/`；后续新增同系列笔记直接落入该文件夹。

## 命名

`<标题或内容主题> <类型>.md`，类型为 `笔记` / `指南` / `手册` 之一。索引表标题列的链接指向 `media-note/` 下的相对路径（含分类/系列目录），发布脚本按此解析。
