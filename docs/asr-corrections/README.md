# ASR 还原对照 · 索引

视频字幕由语音识别生成，专有名词会被**系统性地误识别**。误识别是由讲者口音决定的——同一个 UP 主会在不同视频里反复犯同样的错。因此本目录**按讲者（UP 主）组织**，而不是按笔记组织。

## 目录说明

| 文件 | 内容 |
| --- | --- |
| `AI大模型码农.md` | Agent 方法论/进阶篇/项目篇系列（第 7/9/10/11/12/13/14/15/16 集）的 ASR 还原对照表 |
| `技术爬爬虾.md` | Pi 使用手册的 ASR 还原对照表 |
| `咲凌_Arisa.md` | Superpowers 笔记的 ASR 还原说明（句子级噪声） |
| `iwenwiki.md` | Agent Skills 手册的 ASR 还原对照表 |
| `存疑清单.md` | **所有待人工审核的存疑项**（集中于此，与对照表分离） |

- **对照表**（`<作者>.md`）：AI 已确定的「误识别变体 → 正确术语」映射，可直接复用，不必重新推导。
- **存疑清单**（`存疑清单.md`）：倾向性判断、无法确认、需要人工核对的项，按作者分组，是人工审核队列。

## 怎么用

1. **整理新笔记前先查对照表**。确定讲者后，读该讲者的 `<作者>.md`，命中就别再推导一遍。
2. **发现新变体补回对应作者的对照表**（变体列追加、出处列加新笔记）。
3. **拿不准的进存疑清单**，别硬塞进对照表——对照表只放确定的，存疑的单独列在 `存疑清单.md` 待人工审核。
4. 笔记正文只留一行指针（指向作者文件 + 存疑清单），且指针必须放在 `## 副产物导航` 段内。

本目录在 `media-note/` 之外，发布脚本不遍历，**不会发布到公开站点**。

## 查证规则

- **必须联网查证**：包名、CLI 命令名、启动参数、文件路径、API 方法名、技术术语缩写。
  标注「存疑」不等于免责——凭谐音猜出来的包名基本都是错的。
- **可以只标存疑**：模型版本号、UP 主昵称、视频未展示的命令原文、无法穷举的第三方列表。
- 查证后的结论写到 `存疑清单.md` 的「已查证」分组，留作回看。
